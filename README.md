# AI with Python - DigiSkills Course Practice 

Welcome to my code repository for the **AI with Python** course by [DigiSkills](https://digiskills.pk/). This repository serves as a comprehensive collection of my coding practice, hands-on implementations, and exercises completed throughout the training program.

## About This Repository

This project tracks my learning journey from foundational programming concepts to advanced Artificial Intelligence implementations. 

The code is strictly organized **week-by-week** and **lecture-by-lecture**, making it easy to navigate the progression of topics. Whether you are looking for basic Python syntax or advanced Machine Learning algorithms, you can find the exact code implementations structured exactly as they were taught in the course. Everything goes from absolute beginner level to advanced complete code.

## Course Structure & Folders

The repository is divided into modules to match the curriculum:

* **Python Fundamentals**
  * Environment Setup (Jupyter, Anaconda)
  * Variables, Data Types, and Operators
  * Control Flow (If/Else, Loops)

* **Data Science Libraries**
  * Numerical computing with **NumPy**

* **Machine Learning Basics**
  * Introduction to Scikit-Learn
  * Supervised Learning (Linear Regression, Classification)
  * Unsupervised Learning (Clustering)

* **Advanced AI & Deep Learning**
  * Artificial Neural Networks (ANNs)
  * Natural Language Processing (NLP) basics
  * Final course projects and advanced implementations

## Getting Started

If you want to run or review this code on your local machine, follow these steps:

### 1. Prerequisites
You will need to have Python installed, along with Jupyter Notebook. The easiest way to get everything set up is by installing the [Anaconda Distribution](https://www.anaconda.com/).

### 2. Clone the Repository
Open your terminal or Git Bash and run:
```bash
git clone https://github.com/Adam-ur-Rehman/AI_with_Python_DS_Course.git
cd AI_with_Python_DS_Course
```

### 3. Run the Code
Navigate to the specific week and lecture folder, and open the `.ipynb` (Jupyter Notebook) or `.py` files to view the code in action.
